1. 在「唱片清單」先查看 Discogs 需求與版本行情，選定要找的唱片。
2. 到「進貨與 Sheets」的「先確認需求，再找進貨來源」，選擇該 Discogs 版本，勾選平台搜尋；可改用日文名稱或唱片編號。
3. 「配對比價表」會列出貨源 × Discogs 版本。名稱相關只標示可能匹配，已知格式不同的貨源不自動配對。
4. 用格式篩選查看黑膠、CD、卡帶；每個壓片版本獨立比較。格式待確認的來源不可當成確定匹配。
5. 按「核對／補成本」，填含運進貨總成本、預定售價、品相，並確認版本與是否已收貨。再次儲存會更新報價確認時間。
6. 表格顯示原幣價格、台幣售價、標價差、毛利／毛利率、費用、淨利／淨利率及每項待辦。支援搜尋、淨利排序、已核對與可建草稿篩選。
7. 已持有，或已確認可立即採購庫存及出貨天數，再核對版本、品相與利潤，可建立草稿。未進貨不必勾選持有；草稿仍不等於刊登。勾選草稿後可匯出 Quicklister 檔，在 Discogs 核對後操作。
8. 點「更新行情 → 找貨比價 → 同步 Sheets」一次完成更新。Analysis 優先採用人工預定售價，包含毛利、毛利率與淨利；Comparisons 是所有可能配對的本機計算快照。Sheet 的 Inputs 與本機費用、匯率仍可不同。

計算定義：標價差＝參考售價－來源商品標價；毛利＝參考售價－含運進貨總成本；淨利＝毛利－費率、出貨運費、包材與風險準備。兩種利率以售價為分母。Discogs 最低掛牌價不是成交價；未填匯率或總成本顯示缺項，不會補零或虛構毛利。

## 評分與使用限制

- 權重：需求 30%、預估淨利率 35%、稀缺 15%、跌價動能 20%。正規化是初始人工設定，未經回測。
- 需求分項：`min(want/have / 5, 1)`；have 為零以 1 計。
- 淨利分項：`clamp(net_margin / 0.4)`；缺成本或有效匯率給 0.5 並明確提示。
- 稀缺分項：有在售時 `1/(1+(在售量-1)/3)`；零在售不觸發規則。
- 動能分項：`clamp(七日跌幅 / 0.4)`；缺同幣別基準時給 0.5。採 7 日前至 9 日前的最近快照，不把任意很久以前資料當七日基準。
- 需命中規則且分數至少 60 才入通知佇列；85 分以上或命中跌價規則標急件。
- 同盤成功通知後冷卻 7 天，同幣別再跌 15% 可提前重新評估；跳過冷卻 30 天；要進貨／觀察停止一般選品提醒。
- 同一天依台北日期只保留最後一次快照。未來高頻 watch 會另設觀測表，保留日內變化。
- 售價是最低掛牌价，可能對應較差品相；不是成交中位數、預期成交價，也不能推導周轉速度。
- 12% 合計費率、600 元淨出貨運費、50 元包材只是文件衍生的測試假設，請在 `.env` 改成自己的數字；不是經查證的平台現行費率。
- 進貨成本應包含你要計入的進貨運費、代購費等；退款準備可填 `RISK_RESERVE_TWD`。稅務及費用細項尚未建模。
- 沒有自動估日本賣家成本，沒有憑空補齊缺資料。
