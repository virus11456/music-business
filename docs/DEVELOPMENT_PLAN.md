# 開發整理與下一步

## 定位

日本壓片的西洋英文專輯，黑膠優先；以 Discogs 為銷售目標。系統協助找候選、累積行情、比較成本、排序並提醒。進貨付款、品相、實拍、寄件、退款仍由 Frank 處理。

這次要求是整理文件並著手開發。本次交付範圍為 Phase 1 後端增量，並未宣稱整個生意系統完成。

## 文件取捨

| 文件差異／缺口 | 開發決定 |
|---|---|
| 舊後端規格說不做前端、掃描；總說明與自動化文件列入 Phase 1 | 以總說明整合順序為主，先做後端含掃描；Dashboard 作下一個增量 |
| 範例主題含 city pop、台灣民歌，但商業定位是日本壓片英文專輯 | 首版掃描主題要求指定歌手，國別 Japan、格式 Vinyl 預設；不擅自擴充選品方向 |
| UNIQUE(release_id,captured_at) 無法達成每日唯一 | 加台北日期欄位，改為 UNIQUE(release_id,captured_day) |
| 每日唯一與三小時 watch 日內觀察衝突 | 首版每日快照；後續 watch 增設日內觀測表 |
| 提及 marketplace/search 但未核實可用 | 不使用不確定的 marketplace/search；唯讀 stats adapter 嚴格檢查欄位，需真實 probe |
| 缺成本可估亞洲最低價，但没有可驗證資料來源 | 不自動造價；暫給中性分並標示未驗證利潤 |
| want/have 被描述為流動性 | 僅當需求代理值，不能表示售出速度 |
| 填成本後稱為實際淨利 | 改稱估算淨利；賣出前不可能知道實現損益 |
| 通知記錄與成功送出未分開 | 先寫 outbox，收到成功回應才寫 alerts_sent |
| API 每程序限速會在 cron 重疊時超標 | 同一 SQLite budget 跨程序協調，1.1 秒間隔；cron 再使用共用鎖 |
| 上架失敗自動重試可能重複刊登 | Phase 2 必須加刊登識別與遠端核對；寫入 timeout 不可盲目重試 |
| 照片上傳位不等於平台有商品照片 API | Phase 2 先核對平台支援；不能承諾本地上傳即同步商品頁 |

## 已完成

- Python 3.11+ 無額外套件的可執行後端、SQLite 資料模型與版本標記。
- 每日快照、成本、歷史匯率、評分組成、决策歷史、掃描主題、通知佇列、任務紀錄。
- 掃描分頁續跑、抓取單筆失敗不中止整批、唯讀 probe、429 限次重試、讀取額度標頭。
- 三條選品規則、評分、冷卻、成本或匯率修改後重算。
- Telegram 預覽與明確啟用的發送實作、未知結果不盲重試。
- 示範資料、選品報告、測試與部署範本。

## 下一個增量：完成 Phase 1 驗收

1. Frank 在本機填入 Discogs token，指定第一批版本，執行 probe，修正實際欄位映射。
2. 補上總覽與決策收件匣。沿用 Python／SQLite 架構，由 Dashboard 讀評分結果與寫決策，不在頁面內重新計算。
3. 完成每日合併摘要、連續抓取失敗告警與通知異常核對介面。
4. 補 Telegram 接收資訊，經 Frank 指定接收對象後發一則測試，確認再啟用排程。
5. 以 20–30 個實際版本人工核對：版本正確、價格與品相可比、貨源可取得、估算費用完整。
6. 累積至少七日可比較快照後，再評估跌價訊號。記錄誤報原因後調整門檻，不能把示範分數當作驗證。

## Phase 2：選品到上架

- 補掃描／監控／分析頁與日內 watch，Telegram inline 按鈕驗證 chat/user 並持久化 callback 去重。
- 以「實際持有的每張唱片」建立獨立 item ID，不能只以 release ID 當庫存；同版可持有多張、成本與品相各異。
- 每件持有物輸入進貨來源、實際成本、media/sleeve 品相及照片。
- 上架前版本確認、幣別與賣家帳號校验、ready 狀態規則。
- 人工啟動批次刊登；加 `submitting / uncertain / needs_review` 狀態，遠端確認後才更新庫存，避免 POST 重試造成重複上架。
- 確認平台照片支援及 seller 寫入權限；probe 不應真的發一張測試刊登以測權限。

6. **上架階段再提供**：賣家帳號狀態、常用庫存表、品相與照片流程、實際出貨地。

依使用者確認的流程，先從 Discogs 選定有需求的版本再搜尋平台；來源搜尋結果連回指定版本，明確格式衝突不配對。加入黑膠／CD／卡帶篩選，每列顯示來源價、總成本、參考售價、標價差、毛利率、淨利率與上架準備缺項。報價可編輯，預定售價與持有商品需人工確認。未補成本與有效匯率時不顯示假毛利。正式刊登仍未接通。
