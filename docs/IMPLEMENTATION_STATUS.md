## 已有功能的實際邊界

- 前端在 Vercel，後端與唯一正式排程在 VPS；Mac 不應啟動第二個正式排程。
- 收集是保存主題的分頁抓取，不是全平台完整庫存。未配對保留，待到期或身份變更再查。
- Vinyl／CD／Cassette 分類，Label／編號輔助配對；同名不代表相同壓片，Want 不等於已有買家訂單。
- 主清單可按 Want、毛利、毛利率排序與最低 USD 售價篩選，預設最佳貨源、其餘折疊。
- 人工確認版本、品相、供貨／出貨時間仍是上架前資料要求；不要求一定先買入。
- Skill 已納入專案，含唯讀診斷腳本。資料庫排程紀錄不能證明執行緒此刻存活，需查 API。
