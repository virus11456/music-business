# 採購清單與貨源檢查

入口：唱片清單 → 對應進貨賣場 → 加入採購清單。面板位於唱片清單上方。

- 預設只看 48 小時內行情、貨源與採用成本；關閉篩選可檢視歷史。過期不等於已缺貨，未知供貨不等於現貨。
- Label 為已取得的 Discogs 資料，不能聲稱來源 Label 已吻合。編號須完整一致，標題推測只作線索；衝突不可被舊人工確認蓋過。
- 清單每筆 1 件；同一連結只加入一次，避免同商品多個候選版本重複計算。需先移除才能換另一版本。
- 只有需求及價格完整、正毛利、近期資料、來源現貨且人工確認版本的項目計入合計。其他項目保留原因。金額為估算，未提供的運費不視為零成本已核實。
- 賣家分組需自行填寫相同名称（離開欄位後套用），不同平台不合併；未知賣家各自列出。尚無可靠賣家 ID，不自動合併運費。
- localStorage 僅存選取識別與自行指定的賣家，不保存可當作最新價格的快照；每次使用伺服器回傳的配對重新解析。未找到或身份不符保留待核對。
- 同瀏覽器持久保存、最多 200 項，並非帳號或跨裝置同步；清除瀏覽器資料會失去清單。同瀏覽器登入者共享這份本機清單。
- CSV 帶檢查原因、時效、原幣價格與 TWD 估算；包含待核對項目供人工審閱，絕不作為已下單、已持有或已刊登依據。
